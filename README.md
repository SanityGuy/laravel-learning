# Laravel Task Manager

A task management application built while learning Laravel, PHP, Blade, and database-driven web development.

## Tech Stack

- PHP
- Laravel
- Blade
- Tailwind CSS
- Vite
- Eloquent ORM
- SQLite or the configured Laravel database

## Current Features

- Dashboard and About page
- Reusable MVC structure with controllers
- Dynamic Blade templates
- Tailwind CSS styling
- Automatic browser refresh during development
- Database migrations and Task model
- Dynamic task listing
- Task creation form with server-side validation
